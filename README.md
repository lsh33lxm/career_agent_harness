# 观复 · Agent Career Harness

![观复桌面端预览](assets/readme/guanfu-today.png)

本地优先的个人职业管理桌面应用，集中管理机会、项目证据、能力、简历与职业历程。

- 关键修改需人工确认；不会自动投递或发送消息。
- 支持 Demo Mode，以及本地/云模型的手动配置。

## 本地开发

```bash
npm ci
python -m pip install -e ".[dev]"
npm run dev
```
